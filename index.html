Quando faz sentido chamar

Os três cenários que mais aparecem, e o que costuma estar por trás de cada um.

A integração quebra e ninguém sabe onde

Falta log, falta rastreio e o erro aparece dias depois, em outro sistema. O primeiro passo é tornar o fluxo visível.

Só uma pessoa sabe mexer

O sistema funciona, mas o conhecimento não está escrito em lugar nenhum. Documentar é o que transforma risco em ativo.

O fornecedor mudou a API

Quando a integração está grudada na regra de negócio, qualquer mudança externa para o processo. Uma camada no meio resolve.
